## 1 | 下载与构建
任何版本都可以在 [Release](https://github.com/CoderFrish/LemonMint/releases) 中找到，也可以通过以下步骤构建
```shell
# 克隆LemonMint的代码仓库
git clone https://github.com/CoderFrish/Lemon.git
cd Lemon

# 应用LemonMint的补丁并创建Paperclip Jar文件
./gradlew applyAllPatches && ./gradlew createMojmapPaperclipJar
```

## 2 | API
```xml
<dependencies>
    <dependency>
        <groupId>me.coderfrish.lemon</groupId>
        <artifactId>lemon-api</artifactId>
        <version>1.21.8-R0.1-SNAPSHOT</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
```
